# RS-D-MADDPG 迁移接口设计（未接入训练）

仓库已跟踪文件中没有 RS-D-MADDPG 的 Actor、Critic、风险价值估计器或训练/回放代码；也没有可核实的论文原动作 `d_max` 和决策步长。P2-0 因此只定义对接数据契约，**不声称与原实现兼容**。正式迁移须先取得原论文源码、配置/模型权重及授权使用范围，并核对动作归一化、风险目标、CTDE 输入与训练时钟。

每个任务时刻输入：按稳定 UAV ID 排序的活动 `service_uav_ids`，每个服务 UAV 的三维位置、能量、速度、网络角色、BS 路径状态、任务群锚点、PoI 需求和当前任务状态；附 `agent_mask`、`node_id↔slot` 映射和任务群生命周期事件。没有服务资格的 CM/CH/BR 不进入动作集合，但仍可作为通信约束参与观测。网络路径可用不等于 PoI 被有效覆盖；覆盖需同时满足感知几何、任务驻留和通信回传定义。

最小迁移路线：先在独立 Part2 分支复刻固定六机输入输出并用原实现的已知样例核对；然后共享 Actor 参数，对可变代理数采用按稳定 ID 填充至 K 个槽位并带有效 mask。集中式 Critic 接受同一槽位的全局观测/动作及 mask，屏蔽空槽对风险敏感分布式价值估计的贡献。K 依据开发数据的任务群大小分布选定；超出 K 必须显式拆分或拒绝，不能静默截断。保留原风险估计目标与 CTDE 更新，先验证固定六机兼容，再训练可变规模。

加入时分配新槽、初始化策略隐状态；退出时发出终止标志、清除隐状态与槽位映射，经验回放保留当时的真实 mask/ID。任务群重构只改变下一个决策时刻的成员映射；未到动作周期的覆盖目标应明确继续/取消，不能重复推进 UAV。CH 更换只更新网络观测，不自动清空 Actor 状态。真正服务节点故障、持续 BS 路径丧失或 PoI 紧急变化可进入事件处理，但需与正常周期动作的优先级和时间戳统一。

开发种子用于选择 K、2/3/5 s 周期与迟滞参数，冻结后再用留出种子评价。1 s 和 10 s 仅作参考；R4-1 单 seed 不能证明最佳周期。
